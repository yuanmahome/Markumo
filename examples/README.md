# 欢迎使用 Markumo

这是您文档目录中的真实示例工作区。可以修改、保存、重命名这里的文件；帮助菜单能再次打开它，已有文件不会被覆盖。

1. 在左侧展开 01-Markdown，单击基础语法文件，再双击标签固定它。也可从“文件 → 打开文件”选择一个文件，或从“文件 → 工作区 → 打开文件夹”打开自己的目录。单文件只管理当前标签，工作区增加目录树和目录搜索。
2. 在“视图 → Markdown 编辑模式”依次试用实时排版、源码编辑、双栏预览。实时排版可以直接修改文字、列表、表格；需要精确控制 Markdown 时切到源码模式。
3. 打开图片与链接示例，选择图片或图表进入编辑；悬停观察放大入口，点开放大预览。图表内容使用 Mermaid 源码编辑；外部图片需要授权，未授权时显示占位提示。
4. 从“编辑 → 在文件中查找”搜索“示例”，再试目录搜索。跨文件替换先核对差异再应用。
5. 拖动标签到编辑区边缘分栏，或使用“视图 → 编辑器布局”。在另一分栏打开同一文件观察同步编辑。
6. 选中文字后复制；跨段选择默认复制 Markdown，使用编辑区菜单的纯文本复制可去掉格式。设置中可以关闭跨段 Markdown 复制。
7. “视图 → 自动换行”控制普通编辑器；设置中的 Markdown 排版另有代码块换行选项。两者默认开启，只影响显示，不写入换行。
8. 打开首选项调整主题、字体和语法配色。默认鲜明 vivid；切换柔和 soft 后会记住您的选择。
9. 打开完整语法或导出验收文件，从“文件 → 导出”选择 HTML、Word、PDF 或 PNG。Windows 原生 PDF 使用 WebView2 打印；其他平台尚未实现原生 PDF。Word 图表转换成高清 PNG，仍保留可编辑正文；失败内容会明确提示。
10. Ctrl+O 打开，Ctrl+S 保存，Ctrl+F 查找，Ctrl+H 替换，Ctrl+Shift+P 打开命令面板。当前快捷键以设置中的绑定为准，可切换 Markumo、Fleet、Typora 方案。

反馈问题请访问 [GitHub Issues](https://github.com/yuanmahome/Markumo/issues)，附上系统、重现步骤及去除隐私内容的样例。菜单“帮助 → 打开示例工作区”可随时返回这里。
