基线为 main 的 `93890445a0d4bc13f72df16aac6d980b00964c99`。本任务暂停此前发布请求，不改版本、不推送、不创建标签或 Release。测量使用独立 Windows WebView2 Release 构建 `p0-before`，同一进程探针、固定语料，每场景三轮；自然回收、主动 GC 分开记录。原始记录为本地忽略目录 `test-results/phase042/native-p0-before/results.json`。

## 测量口径

Rust Private/Working Set 与 WebView2 子进程 Private/Working Set 分列；子进程 Working Set 合计可能重复共享页，不称为唯一物理占用。JS Heap、DOM、监听器、编辑器、Worker、Blob、Canvas 与可观测图片像素分别报告。Observer 探针用 WeakMap/WeakSet 记录显式注册，不持有目标；计数不是 GC 可达性证明。启动指标包含进程启动至 CDP 观察到就绪的采样开销。每轮 30/60/120 点在没有主动 GC 的循环中采样，场景结束另记录主动 GC 参考。

## Phase 2 资源治理

- 可见性按 Document、真实 Pane root 与 margin 共享 IntersectionObserver；每个目标独立派发，最后订阅移除时解除观察、清理 root/margin 键及 document 监听器。200 目标专项从 200 个实例降至 1 个，目标仍全部被观察；不缩小视口或取消渲染能力。
- 恢复代际令牌改为按规范文档 metadata 对象存放的 WeakMap，关闭或替换文档不会重新匹配旧请求；销毁标志使迟到结果失效。清理已关闭文档的 Text/摘要、保存/丢弃后的摘要与 dispose 后的 Text，不删除未认领的磁盘恢复记录。
- Workspace 完成、失败或命中已打开文件时退休 Pane 意图；新打开前移除已销毁 Pane 的请求消费者。destroy 清理搜索、替换、索引和 pending 容器；保留查询偏好，正常关闭搜索不清空用户历史。
- `node tests/lifecycle/ownership.mjs` 4/4；`node tests/phase042/render-tasks-phase2.mjs` 全部通过；`pnpm typecheck` 通过；`pnpm test:smoke` 15/15。原生三轮 A/B 在联合阶段复测，不能用实例数量减少直接推算进程内存百分比。

## Phase 3 源码保留与增量同步

复用 SourceBridge 的块 ID、原始 raw、区间、prefix 与 tail。在已变更块序列化前，尝试可验证的局部源码 Patch：只定位唯一变更的文本叶子；源码映射保留实体、反斜杠转义、CRLF、嵌套/缩进代码的行前缀。候选必须重新解析为完全相同的目标 PM 节点才接受，匹配及解析次数有上限。必要的 Markdown 边界改变只扩展到接触的强调分隔符。标题级别、任务勾选和图片地址使用同样的语义证明，不改动周边标记。未知块继续沿用原始源码保护机制。

普通段落或标题的非换行源码修改只解析所在块，引用环境或块类型变化退回完整权威解析；不引入跨版本全文缓存。结构性编辑继续使用原有序列化与表格补丁。跨 Pane 的一次规范 Text 更新只生成一次临时字符串，保留原有共享历史、保存基线和版本校验。

最终扩展语料在同一套断言下，历史 main 只读覆盖层为 49/73，当前为 73/73。新增测试同时覆盖实体/转义、重复文字、标记中的文字、字面 Markdown 标点、强调边界删除、未闭合围栏、嵌套及缩进代码、新增代码行、ATX/Setext、任务、图片、表格、模式循环，以及固定种子 120 次编辑/撤销/重做/模式切换。独立字符串 oracle 与 saveSnapshot 一致。另沿用空行与表格交互回归，不将构造 PM Selection 的测试称为真实鼠标验收。

严格等待两个 Live Pane 均挂载后，30 次普通源码修改（含 Undo/Redo）的 tokenize 总输入：85,116 → 13,244 字符，调用 160 → 192 次，输入范围约减少 84%。候选块仍重新解析证明语义；这是开发服务器内的算法专项，不能当作原生 Release 内存数字。该次运行的同步派发中位数 2.70 → 1.50 ms，最大 5.5 → 3.2 ms，仅作本机诊断参考。测试同时验证两边 Bridge 在 Undo/Redo 后一致，以及 dirty 状态正确。

补查复现了实体、标记与缩进造成的光标偏移：旧反向定位把源码偏移直接当作显示文字偏移；旧正向定位无法匹配已经解码的完整文本。现在正反方向共用稀疏词法边界映射，覆盖实体、转义、标题、围栏、缩进代码和嵌套引用；另验证 Source→Live→Source 的实际编辑器光标，以及六种结构/引用边界的增量结果与完整解析一致。优先尝试可原样插入的文字并证明语义，避免为合法的 `BELOW_IMAGE` 多加转义。

区间使用规范文本的 UTF-16 偏移，不是磁盘字节偏移。原始 CR/LF/CRLF 由 DocumentManager 的 lineEndings 扩展独立跟踪，CM Text/Bridge 使用规范换行；saveSnapshot 还原换行，Rust 按编码/BOM 写入。此流程保留混合换行，无需另外常驻整份原始字节副本。

`tests/lossless/native.mjs` 在真实 Windows Release 中分两批测试 29 个磁盘夹具，使用原生授权、编码器、Ctrl+S、关闭、重开及 SHA-256，分批是为遵守最近文件 20 项上限。覆盖 20 个 LF/CRLF 变体、超出既有 Live 预算的大文档、UTF-8 BOM、混合 CR/LF/CRLF、UTF-16 LE/BE 有无 BOM、GB18030 和 Windows-1252。基线及优化后 no-op 字节均一致；其中 20 个夹具进一步验证局部插入及 Undo/Redo 后的精确字节补丁，保留编码、BOM 和所有原始换行。复杂 UTF-8 另测中文插入、Undo 后原始字节、Redo 和重开。外部修改的真实磁盘版本冲突被拒绝，外部字节保持原样。保存完成以 FileController 接受新的原生磁盘版本为准，没有通过仅比较内存字符串替代落盘。

独立窗口新增按所有权收敛的关闭兜底：只有曾持有文档且启动完成的 detached 窗口，在最后文档移交完毕、文件操作结束后才发起已有 WindowCloseGuard；初始空窗、忙碌状态及卸载后都不关闭。关闭触发不再只依赖 commit 事件，超时状态查询收敛也会触发。专项生命周期为 5/5，长循环证据见联合验证。

新浏览器无损与资源所有权专项已加入 smoke/regression 与 GitHub Quality Gate；原生字节及性能脚本保留 Windows Release 前置条件。未修改版本号、权限、发布流程或用户文件配置。

补充的真实标题命令复现为 71/72：ProseMirror commands 的 `setBlockType` 给所有块同一个 attrs 对象，丢失 sourceId，标识插件随后为它分配新 ID，绕过原始 raw 复用。新增独立的 `setSourceBlockType` 命令，使用已安装 Transform API 的逐节点 attrs 回调，保留每块标识；统一标题快捷键、Alt 快捷键、格式命令。73 项最终测试包含真实 Ctrl+3、格式命令的多标题选区、Undo/Redo；原生 Ctrl+3→Ctrl+S 也精确验证原始空格、闭合标记和 Undo 后磁盘 SHA。

独立窗口详见 [六轮窗口报告](p0-window-comparison-20261028.md) 和 [窗口摘要](p0-window-results-20261028.json)。基线三轮分别成功 49/120、120/120、21/120；失败时文档已经到达主窗口，空源窗口没有关闭。优化后三轮均完成 120 次，共 360 次；30/60/120 点均只有主窗口、一个文档、一份活动 Source CM，没有残留 ghost。正式测试先用 computer-use 激活隔离窗口，后由生产原生移交 API 驱动，不能称为 360 次物理鼠标拖拽。窗口测试不主动 GC，三轮几何与 Pane 数有差异，不用它推算总体内存下降百分比。此前遮挡/不允许 set_focus 的预试验未纳入正式三轮，未放宽 ACL。

### 限制与仍需验证的范围

- WebView2 Private 在长循环后仍高，24MP 原图缩放约 1 GiB 的峰值仍存在。活动资源回收和 JS heap 稳定不能证明 native/GPU/解码缓存全部回收；本次没有做其完整分配归因。后续应以 WPR/ETW、native/JS heap retainer trace 区分运行时高水位和真实存活引用，再决定图片分块/原图读取等后续优化，不通过生产主动 GC 制造下降。
- 增量候选必须证明解析语义；无法证明的结构性编辑仍走既有受影响块序列化，可能规范化该块的标记风格。未改块复用原始 raw，未知节点保留源码；这不等于所有扩展任意结构改写都能逐字保持。受保护原子或纯 Markdown 标记内部没有等价显示光标时，定位吸附到可表示边界。
- 超大 Markdown 沿用原有 Live 预算并落到 Source/Split 的保护行为，字节测试通过；没有承诺其完整 Live 渲染。撤销历史、草稿、恢复、渲染与权限保护均未为性能而关闭。
- Windows 窗口测试采用真实进程/API/命中检测及 computer-use 激活；没有将 API 往返称作大量物理拖拽。IME 主要复用合成 composition guard，长句候选、手写、低内存、不同 GPU/高 DPI/多显示器仍需真人补验。Linux/macOS 的原生 WebView GUI、真实 Typora 对照本次未测，不能称为完整通过。

本次所有修改和中文提交均在 main。新增纯辅助模块承载源码补丁、偏移和格式命令，既有巨型控制器只作接线修改。版本仍为 1.1.1，没有推送、Tag、Release 或安装测试程序到日常环境。
