## 所有权表

| 资源 | 创建与拥有者 | 释放/边界 | 审查结论 |
| --- | --- | --- | --- |
| 规范 Text、保存基线、Undo/Redo | DocumentManager 的 CachedDocument | 最后标签引用关闭时 release；dispose 清空 records | 保持单份规范状态与完整历史；跨 Pane 仅共享不可变 Text |
| 主 CM、PM、SourceBridge | 每个已挂载 Pane 的 manager / MarkdownEditorController | destroyView、模式切换、卸载 | 现有销毁保留；源码局部同步仍需避免整篇重新 tokenize |
| 嵌入代码 CM | CodeBlockView 编辑态 | 安全失焦/离开及 destroy | 展示态零 CM；不禁用编辑或 IME 保护 |
| 可见性 Observer / visibilitychange | observeRenderVisibility 调用方 | 返回的 disposer | 每代码块一个实例及监听器，适合按相同 root/margin 合并订阅 |
| 高亮、KaTeX、Mermaid 队列 | renderTaskQueue / renderers | AbortSignal、数量/字节 LRU、视口/隐藏暂停 | 已有上限和取消，不重复实现 |
| 图片请求、Blob、解码节点 | resources / sharedBlobCache / mountMarkdownImage / ImagePreview | inFlight finally、引用计数、文档释放、src 清空并移除节点 | 沿用既有 Detached DOM 修复；只统计可观测解码像素 |
| PDF LoadingTask、Worker、Canvas、TextLayer | PdfViewer / PdfPage | 代际校验、取消渲染、Canvas 清零、异步 teardown | 已有可见页与像素预算，需继续原生翻页缩放关闭回归 |
| Workspace 打开请求与 Pane 意图 | WorkspaceController | inFlight/pendingReads finally；destroy | latestPaneSeq 未按完成释放；关闭 Pane 的旧意图可累积 |

| 自动保存 | AutoSaveController | 单队列、关闭文档清理、dispose | 已按文档清理 failures/pending，保持原有冲突暂停与重试预算 |
| 恢复快照与缓存 Text | RecoveryController；磁盘归 RecoveryGateway | onSaved/discard/dispose | 摘要/代际条目不完整回收；dispose 不能阻止迟到结果回填 |

| 独立窗口与跨窗移交 | useAppShell / tabDetach / Rust Window | 确认后销毁源引用；dispose-window 与原生 Destroyed | 沿用已有握手、权限转移及失败回滚，另做长循环验证 |

## 测量口径

Rust Private/Working Set 与 WebView2 子进程 Private/Working Set 分列；子进程 Working Set 合计可能重复共享页，不称为唯一物理占用。JS Heap、DOM、监听器、编辑器、Worker、Blob、Canvas 与可观测图片像素分别报告。Observer 探针用 WeakMap/WeakSet 记录显式注册，不持有目标；计数不是 GC 可达性证明。启动指标包含进程启动至 CDP 观察到就绪的采样开销。每轮 30/60/120 点在没有主动 GC 的循环中采样，场景结束另记录主动 GC 参考。

## Phase 2 资源治理

- 可见性按 Document、真实 Pane root 与 margin 共享 IntersectionObserver；每个目标独立派发，最后订阅移除时解除观察、清理 root/margin 键及 document 监听器。200 目标专项从 200 个实例降至 1 个，目标仍全部被观察；不缩小视口或取消渲染能力。
- 恢复代际令牌改为按规范文档 metadata 对象存放的 WeakMap，关闭或替换文档不会重新匹配旧请求；销毁标志使迟到结果失效。清理已关闭文档的 Text/摘要、保存/丢弃后的摘要与 dispose 后的 Text，不删除未认领的磁盘恢复记录。
- Workspace 完成、失败或命中已打开文件时退休 Pane 意图；新打开前移除已销毁 Pane 的请求消费者。destroy 清理搜索、替换、索引和 pending 容器；保留查询偏好，正常关闭搜索不清空用户历史。
- `node tests/lifecycle/ownership.mjs` 4/4；`node tests/phase042/render-tasks-phase2.mjs` 全部通过；`pnpm typecheck` 通过；`pnpm test:smoke` 15/15。原生三轮 A/B 在联合阶段复测，不能用实例数量减少直接推算进程内存百分比。

最终 A/B、无损覆盖矩阵、修复机制、命令与限制在后续阶段补齐。
