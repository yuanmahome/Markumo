# Markumo 1.2.5

- 修复跨窗口成功移走最后一处文件标签后，主窗口、文件关联窗口仍保持打开的问题。仅在移交确认完成且源窗口无剩余文档或任务时自动关闭；取消、超时、复制及普通关闭最后一个标签均不会误关窗口。
- 跨窗口拖动只移走被拖动分栏中的标签。双栏都显示同一个文件时，源窗口保留另一处视图，文本与未保存状态保留，双方文件授权相互隔离。
- 主窗口移空后安全迁移主会话所有权，保留剩余文件与工作区恢复信息；目标窗口可继续编辑、保存和打开新文件，重启后恢复会话。迁移失败时保留源窗口。
- 完善移交状态查询、并行移交、组合输入保护、恢复快照保护及窗口资源释放，避免丢失提交通知或异步回调导致误关窗口。其他活跃窗口正在使用的恢复快照不会被当作遗留草稿删除。
