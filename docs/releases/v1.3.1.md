# Markumo 1.3.1

- 全局搜索默认在独立窗口打开。上方是匹配结果，下方是源码，可用「编辑」和「应用修改」直接修改文件所属窗口的编辑内容，继续使用原有的保存和撤销。点击右下角「打开查找窗口」或按 Ctrl+Enter 可把当前搜索停靠到主窗口底部。
- 搜索范围平铺显示。右上角的文件掩码与排除文件掩码支持下拉选择和手动填写。
- 「已打开文件」只搜索当前窗口仍打开的标签。「所有窗口」同时搜索各编辑窗口当前打开的文件，包含未保存内容。各窗口保留自己的搜索条件和结果。
- 修复部分中文输入法按键事件下 Ctrl+Shift+F 无法打开全局搜索的问题。
- 修复窗口较矮时设置左侧分类被页脚遮挡的问题。
