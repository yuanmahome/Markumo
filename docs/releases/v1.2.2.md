# Markumo 1.2.2

- Word 导入改为应用内置的原生 DOCX 解析，无需安装任何外部转换程序。支持标题、常见文字格式、多级列表、表格、链接、图片和脚注；导入后直接打开保存的 Markdown 文件。
- Word 导入先解析再选择保存位置，提供取消、结构化提示和资源预算；图片写入独立资源目录，失败时保护已有目标和图片。宏文档、危险 ZIP/XML 和越权路径会明确拒绝。
- 改善 Word 往返转换：带尺寸的图片可再次嵌入 Word，保留比例和替代文字；修复跨编号实例的列表层级、表格对齐及代码段落识别。
- 修复中文标点旁的加粗识别，例如 `**何时用：**这样`；实时排版、预览、复制和导出采用一致规则，源码不变。
- 修复合法单行 YAML 数组被误判为复杂 Front Matter；局部字段编辑保留原始顺序、引号、注释和换行。
- 实时排版隐藏链接引用定义的正文占位，通过引用链接右键菜单编辑；更新定义后同步链接目标，保留原始定义和源码格式。
- 区分示例资源初始化与首次展示状态，修复首次启动和帮助菜单打开示例工作区，并保护旧会话、文件关联启动和用户修改的示例。

Word 与 Markdown 保留内容语义，不能还原全部页面排版。复杂表格使用 HTML；OMML 公式、SmartArt、图片裁剪、浮动布局和批注等有明确降级提示。Word 导出的公式和图表仍为图片，脚注为文末列表，复杂 HTML 块按源码保留。PDF 原生导出目前仅支持 Windows。
