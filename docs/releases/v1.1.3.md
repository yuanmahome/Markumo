## Markdown 输入修复

- 修复 Live 逐字输入 `[链接](http://129.com)` 时被错误转义、无法转换成链接的问题，覆盖空白文档、分割线后的新段落、列表、引用和表格。
- 保留显式作者转义和代码内容；继续校验链接目标安全性，支持链接标题、平衡括号及嵌套标签。已经保存的转义文字不会被自动改写。
- 完善粗斜体及行内语法转换；输入 `---` 后按回车生成分割线，光标进入下方新段落。

## 开发启动与资源管理

- 开发版使用独立应用标识，避免已运行的安装版通过单实例锁接管开发启动，造成终端正常退出而看不到新窗口。开发数据继续保存在原来的 `.markumo-dev`。
- 普通 TXT、LOG 和代码文档不再安装 Markdown 专属图片资源及导入状态；统一换行文本不再持有逐行换行标记。
- 原生事务历史保存不再生成无用途的 baseline 全文字符串，保留历史、撤销重做、未保存内容和恢复机制。
- 完善编辑器动态模块、渲染任务及文档资源的生命周期释放。

## 验证与限制

- 新增截图流程、空文档及链接输入回归，以及开发/安装版实例隔离检查。保留无损保存、链接安全、Undo/Redo、分栏及资源生命周期回归。
- 普通文本修复前后、Nomo 参考版本的实际 Windows Release 进程树、JS Heap、读写和关闭曲线见 [P0.3 调查报告](https://github.com/yuanmahome/Markumo/blob/v1.1.3/docs/performance/p03-text-architecture-20261029.md)。数据不支持宣称进程总内存大幅下降，也未证明长期运行的原生内存增长已消除。
- Rust 分段文档和 CodeMirror 有界窗口仍为独立实验原型，未启用默认大文件路径。原有文件大小、历史备份及编码限制继续生效；本版本不宣称已经支持完整的 50/100 MiB 文件编辑。
- 本机原生 GUI 验证为 Windows；其他平台的安装包由 CI 构建，原生交互及真实输入法仍需对应环境验证。
