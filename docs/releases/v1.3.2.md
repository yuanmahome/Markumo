# Markumo 1.3.2

- Mini 小窗与普通窗口平滑切换，保留当前编辑内容。退出 Mini 时恢复原来的窗口位置、尺寸和最大化状态；系统开启「减少动态效果」时直接切换。
- 打开新文件时优先复用已有的普通窗口。如果只剩 Mini 小窗，则另开一个普通窗口，保留小窗中的文档。重复打开已打开的文件会定位到原有标签。
- 「关于」菜单集中提供 GitHub、检查更新和打开示例工作区。
- 应用默认在启动后检查更新。发现新版本时，右下角可选择立即更新、稍后更新或跳过此版本；点击提示外部即可关闭。手动检查无更新时会显示「当前已是最新版本」。
- 状态栏用 `8:25` 显示光标行列，移除换行符标识。移动光标不会触发字数重算；选区只在统计面板打开时计算。
