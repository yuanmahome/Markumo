## Markdown 空行与排版

- 根据真实 Typora 与 Markumo 的 Windows GUI 对照结果，修正显式空白段落与 Markdown 源码换行的映射，避免代码块之间出现多余的空白段落。
- 对齐 Live 与 Split 模式的空白段落、代码块间距；空白区域继续支持放置光标、输入、删除及撤销重做。
- 修复空白段落保存、关闭重开后的换行保留，以及含空格、Tab 的空白行在其他位置编辑后发生重排的问题，保留 LF、CRLF 与文件末尾换行。

## 大纲与 Windows 开发环境

- 简化大纲展示，移除条目末尾行号与未完成语法提示，保留能够确认的代码声明，并补充对应回归覆盖。
- 修复 Windows 开发程序继承低完整性级别，导致普通桌面文件被误判为不可写的问题；开发与打包入口统一处理生成产物的完整性级别。
