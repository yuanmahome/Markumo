# Markumo 1.2.6

- Markdown 双栏预览改为渐进式结构分区：优先显示首屏，滚动时准备相邻内容，回收远离视口的分区及媒体资源。取消按文档字符数禁用预览的策略，不因文件大小强制切换为纯文本。
- 重做右下角统计面板，支持字数、Unicode 字符、汉字、英文单词、行数、段落、选区及阅读时间；保留点击展开、外部点击和 Esc 关闭、统计偏好保存。统计复用文本分片缓存，减少连续输入时的重复工作。目前统计口径为 Markdown 源码。
- 优化 Markdown 实时排版：复用解析 token、增加单块无损源码同步及坐标索引，减少选区变化和列表、表格归一化的重复遍历。
- 表格工具栏按当前活动表格复用；搜索关闭后不再枚举所有代码块位置；Live 模式不再为隐藏的源码数学高亮重复全文解析，改善大文档首次输入无响应。
- 补充大文档真实编辑、Undo/Redo、多分栏同步、组合输入段落稳定性、保存重开和源码 SHA-256 验证；修正仍要求所有预览代码块同时驻留 DOM 的旧回归断言。

这是大文件优化的阶段性版本。Live 仍使用全文 ProseMirror 和 DOM，尚未实现分区实时编辑；95 万字符合成文档已可完成本轮 Windows 编辑和保存链路，但持续输入仍有明显延迟，不能视为大文件全功能性能验收通过。

现有文件打开/保存的 16 MiB 容量限制仍在。超过 8 MiB 的文档可能因保存前历史备份预算被拒绝保存；实测 10 MiB 样本遇到此限制，原文件保持不变。单个超出局部排版预算的结构提供源码定位入口。双栏结构索引的编辑增量化、正文统计及原生流式读写仍待完成。

Windows 实测方法、前后数据和失败记录见 [Live 性能报告](https://github.com/yuanmahome/Markumo/blob/v1.2.6/docs/performance/markdown-live-20261109.md) 与 [双栏及统计报告](https://github.com/yuanmahome/Markumo/blob/v1.2.6/docs/performance/markdown-large-20261109.md)。其中性能数据来自发布前标识清晰的隔离诊断构建，不冒充本次四平台正式安装包的逐平台性能验收。
