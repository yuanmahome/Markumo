## Markdown 编辑

- 修复 Live 模式中显式空白段落保存、关闭和重开后消失的问题；空白区域可继续放置光标、输入、删除及撤销重做。
- Live、Source 与 Split 根据实际源码保留额外空行，区分普通块分隔与临时末尾编辑段落，保持 LF、CRLF、文件末尾换行及原有 Markdown 写法。

## 全局搜索与替换

- 使用应用内统一浮窗提供全局查找与替换，支持拖动、调整大小、固定、查询历史、键盘导航和结果右键操作。
- 支持多工作区、指定目录、已打开文件及未保存草稿搜索，提供 Glob 包含/排除过滤。
- 结果按文件分组并虚拟显示，源码预览按需加载并复用单个只读编辑器。
- 批量替换先审阅 Diff，保留文件版本、权限、编码、换行和安全写入检查；打开文件通过可撤销的编辑器事务修改。

## 大纲与工作区

- 大纲显示区分用户偏好、文件能力和解析状态；不支持结构提取的文件自动释放侧栏，支持文件的加载、错误及空状态保留面板。
- 保留活动 Pane 判断、左右自动停靠和用户宽度设置。
- 修复欢迎页打开文件夹后的工作区展示，以及在文件管理器中显示条目和移除工作区的问题。

## 拖放与资源管理

- 统一文件树与标签的窗口内拖放路径，支持中心、标签栏及四方向分栏；已打开文件复用文档状态，保留未保存内容。
- 标签排序保留编辑视图和解析状态，分栏合并释放对应视图；浮标和落点检测合并到动画帧处理。
- 完善 Windows 窗口外释放确认、跨窗口接收、原窗口回拖、移交失败回滚及保存权限归属。
- 独立窗口按需创建；关闭前卸载组件、编辑视图、监听器和预览资源，搜索订阅延迟到实际使用时建立。

## 兼容性说明

- 普通搜索、设置等面板以及单窗口多分栏继续使用同一个 WebView；只有独立文件窗口新增 WebView。
- 搜索正则按行执行；资源超出预算时显示明确提示，不将截断结果当作完整替换范围。
- macOS、Linux 的原生桌面拖放交互与多显示器混合 DPI 行为仍需在对应设备继续验证。
- 60 轮窗口移交测试中，窗口、文档、编辑视图和 DOM 未持续累积；进程私有内存仍有增长，尚未确认严格的平台期。详见[拖放与资源验收记录](https://github.com/yuanmahome/Markumo/blob/v1.1.0/docs/performance/drag-lifecycle-1.1.0.md)。
