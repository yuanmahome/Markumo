# Markumo 1.2.7

- 修复新增统计偏好 `primaryStatistic` 未同步到原生设置结构，导致首选项保存失败，并阻断应用内更新安装、退出前设置保存的问题。
- 字数、字符数、行数、英文单词和阅读时间五种主统计类型均可原生保存并在重启后恢复；缺少该字段的旧设置默认使用字数，其他首选项保留。
- 增加完整前端设置与 Rust 接口的契约回归，覆盖磁盘保存重读、非法值不覆盖旧设置、安装前严格保存失败时停止安装及恢复后重试。

如果旧版已出现 `unknown field primaryStatistic`，其运行中的安装前检查也会阻断后续更新。请先保存全部文档，完全退出旧版，再从本发布页下载并手动运行安装包，保留原用户配置。若退出同样被此错误阻止，确认所有文档已保存后结束旧进程，再运行安装包。

本补丁修复设置保存及更新准备链路；1.2.6 发布说明中的大文件 Live 性能和文件容量限制仍然存在。
