## 编辑体验修复

- 在代码块行号右侧增加细竖线，展示态与编辑态共用同一分隔线；关闭行号时隐藏，并保持原有行号和正文布局。
- 表格后段落开头按 Backspace 时，进入表格最后一行、最后一列；空单元格继续退格会依次向左、向上一行移动。
- 表格左上角按 Backspace 时，仅在整张表格完全为空时删除；其他单元格含文字、图片、公式或空白字符时保留表格，普通文字和选区删除保持正常。
- 修复图片 Markdown 语法右侧空白点击定位，在源码末尾按 Enter 可在图片下方创建正文段落；支持文档末尾、空图片路径及多 Pane 同步，并保持撤销重做。

## 提示精简

- 移除保存成功、新建、重命名、移动、删除、复制链接、导入导出完成、编码转换和模式切换等常规成功提示，保存状态仍在状态栏显示。
- 减少取消操作、自动重载、历史迁移及更新完成时的提示。
- 保留操作失败、文件冲突、权限问题、恢复后待核对等需要处理的提醒，以及耗时任务的进度反馈。

## 验证说明

- 修改前已在 Windows Typora 1.12.4 中实测表格与图片的上述边界行为。
- 增加 Chromium 表格与图片专项回归，覆盖首击定位、空表格保护、普通文字与选区删除、撤销重做、只读、引用/列表容器及多 Pane。
- 原生中文输入法候选窗口，以及 macOS、Linux 的人工桌面交互尚未手测。
