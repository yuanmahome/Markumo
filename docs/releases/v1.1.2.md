## 工作区删除

- 支持直接删除已打开的文件或目录；删除成功后自动关闭对应标签，包括分栏和其他窗口中的标签。
- 删除失败时保留标签及未保存内容；成功删除后清理该文档的恢复快照，并阻止旧保存请求重新创建文件。
- 删除确认中明确提示对应标签会关闭、未保存的修改会丢弃。

## Markdown 智能复制

- 普通复制在单个文本块内输出纯文字，跨段时按默认开启的「跨段自动复制 Markdown」设置保留结构。
- 跨段选择部分标题时保留标题级别，仅输出实际选中的文字；终点恰好位于下一块开头时不生成空标题或额外标记。
- 正向、反向拖选及复制、剪切入口共用规则；Ctrl+Shift+C 继续显式复制 Markdown，并安全迁移已有设置。

## Markdown 源码保留与资源治理

- 局部文字编辑优先更新对应源码范围，保留未修改区域、空行、换行类型及原有标记写法；改进实体、转义、缩进与标题命令的源码定位。
- 缩小多分栏中的重复解析范围，复用渲染可见性观察器，完善恢复快照异步任务和工作区导航资源释放。
- 修复文档移交完成后空独立窗口未关闭的问题，并增加源码保留、资源所有权和工作区删除持续回归。

## 验证与已知限制

- Windows 原生验证覆盖磁盘字节回环、编码、局部编辑与撤销重做、跨窗口移交，以及删除成功、失败和旧保存授权失效；Markdown 无损专项通过 73 项浏览器断言，磁盘 no-op 覆盖 29 个文件。详细数据见[审查与验证报告](https://github.com/yuanmahome/Markumo/blob/v1.1.2/docs/performance/p0-audit-20261028.md)。
- WebView2 长循环后的原生内存高水位、大图解码峰值仍需进一步分析；本次没有宣称完全消除内存增长。涉及结构变化的编辑仍可能规范化受影响块的标记风格。
- 原生 GUI 验证在 Windows 完成；Linux/macOS 原生交互、真实输入法长句和多显示器混合 DPI 仍需在对应环境继续验证。
