# Markumo 1.2.4

- 修复空二级列表被解析为 H2 的问题。加粗、切换标题、撤销和缩进后，正文、大纲及 Markdown 源码保持一致，切换模式不会重新出现已撤销的标题。
- 完善 `$...$`、`$$...$$`、`\(...\)` 和 `\[...\]` 数学公式支持，统一实时排版、双栏预览、源码高亮和导出识别；编辑公式保留原有分隔符与 LaTeX 反斜杠。
- 改善 Typora 风格公式编辑：独立段落输入 `$$` 或 `\[` 后回车进入公式编辑，显示上下分隔符、语法着色源码、实时预览及确认入口；空公式显示占位，行内公式编辑时显示浮动预览。
- 修复公式逐行及整行输入时产生额外转义的问题，保留代码块、行内代码和明确输入的文字转义。
- 完善公式删除、撤销重做及多 Pane 同步，支持空块公式 Backspace、正文两侧按键删除、节点选中删除和右键删除。清空行内公式时直接移除公式，避免残留有歧义的标记。

已有文档中明确写出的转义不会被自动批量移除。中文输入法和公式编辑继续保留组合输入保护。
