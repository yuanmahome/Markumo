# Markumo 1.2.3

- 修复列表和引用中的表格在实时排版、源码和双栏模式间切换后失去渲染的问题。表格每行保留必要的容器前缀，并在保存修改前验证 Markdown 可以恢复相同表格结构。
- 改善 Markdown 和 HTML 表格粘贴、行列增删及列对齐；局部编辑保留周围列表、空行和未修改的单元格源码。
- 导出 PDF、Word、HTML 和 PNG 时，保存窗口默认打开当前文档所在文件夹，文件名沿用原文档名称。未保存文档或源目录不可用时，回退有效配置目录或系统文档目录；再次导出仍需原生保存确认。

原本不符合 GFM 列表缩进规则的 Markdown 不会自动批量转换。GFM 无法表示的复杂合并表格不会被静默保存成错误源码。
