# Markumo 1.2.1

本次更新重点改善文档导出，并为新用户提供可编辑的示例工作区。

- 修复 Word 导出 Mermaid 仅显示源码的问题：图表和数学公式以独立的高清图片嵌入，正文仍可编辑；图片保持实际宽高比，SVG、WebP 转换为 Office 可读格式。
- 修复 HTML/PDF 导出二次净化导致的 Mermaid 样式、箭头和内部资源丢失。PDF 保留可选择、可搜索的正文与矢量 SVG，并等待页面、图片、字体和图表布局准备完成后打印。
- 改善 Word 中文、Unicode、代码换行、Tab、表格列宽及单元格换行；支持源文档目录或已授权工作区内的相对文件链接，越界目标仍会拒绝并提示。
- 改善长代码、长表格与图表的打印分页，修复 PNG 导出画布宽度被长内容撑大的问题。
- 新安装默认开启普通编辑器自动换行、Markdown 代码块自动换行，默认使用鲜明 vivid 语法配色；跨段 Markdown 复制保持默认开启。已有用户显式关闭的设置和所选配色不会重置，自动换行只改变显示。
- 新用户首次启动会打开真实的 Markumo Examples 工作区，包含操作指南、完整 Markdown 教程、11 类 Mermaid 示例、数学公式、代码、配置及媒体文件。示例复制到可写目录，不覆盖已有修改；帮助菜单可再次打开。
- 后续启动恢复上次会话，升级用户和文件关联启动不会被示例工作区打断。
- 同步更新中英文 README，补充实际操作、默认设置与导出平台限制。

## 使用说明

- 原生 PDF 导出目前仅在 Windows 实现；Linux/macOS 会明确提示暂不支持。其他格式沿用各平台的原有导出入口。
- Word 中的公式是图片，不是可编辑的 Word 公式；HTML 块、脚注和目录仍有明确说明的格式差异。特别长的单张图表建议拆分或使用横向页面，以保证阅读尺寸。
- 该版本的 Word 导入采用外部转换；后续版本已改为应用内置的原生实现。
