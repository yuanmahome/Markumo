## 性能与内存优化

- Markdown Live 中的代码块先以轻量形式展示，进入编辑时再创建编辑器，离开后及时释放，降低大量代码块文档的内存占用。
- 为代码高亮和图表渲染增加队列与缓存预算，暂停后台窗口中的非必要渲染，减少滚动和切换时的重复工作。
- 图片按视口加载，正文中的大图片使用降采样预览，放大查看时加载原图，关闭后及时释放。

## 修复

- 修复图片、PDF 和已移除 DOM 的资源滞留问题，改善反复打开、切换和关闭文档后的资源回收。
- 清理关闭分栏后残留的状态，以及恢复草稿中的冗余文本副本。
- 保留代码块编辑、中文输入、查找替换、撤销重做与 Live / Source / Split 模式切换体验。

## 验证

- 新增代码块、渲染队列、图片及分栏生命周期回归测试，并补充 Windows WebView2 Release 验收与性能报告。
- 性能测量结果来自 Windows WebView2；macOS 与 Linux 的实际内存表现尚未测量。
