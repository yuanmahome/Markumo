# Markumo 1.3.0

- 新增原生 Mini 悬浮编辑模式，入口位于主窗口顶部右侧、设置按钮旁。小窗隐藏侧边栏、文件树、大纲和标签栏，提供置顶、拖动、缩放与返回；切换时保留当前文档、编辑模式、光标和撤销历史。
- 全局搜索与替换改为底部工具窗口，支持结果与源码预览分栏、可拖动分隔线、预览显隐、紧凑条件及替换 Diff。当前匹配、选中结果、当前文件和全部替换继续经过版本检查及原有安全写入流程。
- 全局搜索可弹出为独立系统窗口，独立移动、缩放、最小化并重新停靠；共享主窗口的搜索会话，刷新与快速开关不会创建第二套工作区或搜索索引。
- 文件内查找/替换改为编辑器右上角的紧凑悬浮工具条，随编辑器容器宽度调整；窄小区域仍可展开搜索、替换和匹配选项，保留原快捷键与中文输入保护。
- 优化窗口生命周期、过期请求过滤和预览释放，统一 Mini 入口、置顶与返回的 SVG 图标。
- 修复局部 Markdown 源码退出后的 DOM 清理可能覆盖方向键光标和 Shift 选区的问题。
- 修复空白段落粘贴行内 Markdown/公式后，重新打开可能多出空段落的问题。

Linux Wayland 会话下，Mini 会明确提示原生窗口定位限制，可使用 X11 会话；macOS/Linux 的 Mini 尚待实机交互验收。大文件与正则搜索预算沿用现有版本，未扩大文件容量承诺。

实现、测试和性能记录见仓库 `docs/validation/search-mini-20261117.md`。
