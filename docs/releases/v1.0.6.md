# Markumo 1.0.6

本次更新修复 Markdown 即时排版中 Ctrl/Cmd+点击链接需要两次才能打开的问题，并整理开发文件与项目文档。

## 链接导航与编辑

- Windows / Linux 按住 Ctrl、macOS 按住 Cmd 后，鼠标左键单击链接即可直接导航，无需再次点击。
- 导航时保持链接的渲染形式，不展开局部源码、不选中链接文字，也不修改正文、未保存状态或撤销历史。
- 普通单击继续进入完整 Markdown 链接源码编辑，支持光标、选择、粘贴、中文输入及撤销重做；点击其他正文收起源码。
- 拖动鼠标、中途释放或切换修饰键、目标变化或编辑器销毁时安全取消导航，避免误打开或重复打开。
- 保留链接右键上下文菜单，支持内部锚点、相对文件、带锚点的文件链接、HTTP/HTTPS、引用式链接及裸 URL。
- 正确处理文件链接的 URL 查询参数、空格、中文与百分号编码路径；分栏中的文件链接在来源窗格打开。
- 继续使用现有 Tauri 外链接口和工作区访问权限验证，拒绝危险协议及未经授权的本地路径。

## 项目整理

- 精简历史测试脚本、验收报告和冗余开发文档，保留当前链接交互专项回归。
- 重写中文 README，并提供可相互跳转的英文说明；统一项目与更新入口地址。

## 下载与更新

提供 Windows x64、Linux x64、macOS Apple Silicon 和 Intel 安装包。旧版用户可在应用内检查更新；Linux 应用内更新适用于 AppImage，DEB 用户需下载安装包更新。

安装前请保存文档并关闭其他 Markumo 窗口。校验值见 `SHA256SUMS`，更新签名包含在 `latest.json`。Windows 安装包未使用商业代码签名证书；macOS 使用 ad-hoc 签名且未进行 Apple 公证。
